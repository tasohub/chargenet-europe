# Elevator Pitch

## 90-word version

I built ChargeNet Europe, a public-data decision-support tool for early EV charging expansion diligence across Belgium, Germany, France, and the Netherlands. It combines OpenStreetMap candidate-site proxies, Eurostat population demand proxies, and GISCO NUTS geography into a reproducible Python pipeline. The current Phase 4 layer scores 1,973 candidate proxies across 585 demand zones, then stress-tests rankings across five weight sets so hiring managers can see both the recommendation logic and its practical limits. Phase 5 will add MILP facility-location optimization on the same data foundation for constrained site-selection scenario planning.
